DATA FLOW

How Data Flows: Seed → DB → API → Frontend

Component Location Key Detail
seed.ts packages/database/src/ Deterministic LCG (seed=42); upsert with skipDuplicates; runs in ~2min
Prisma ORM packages/database/prisma/ schema.prisma with enums (6 QuestionType, 3 Difficulty, 5 Mastery, 4 AttemptStatus)
Neon PostgreSQL Cloud DB Real-time schema sync; db:push for dev
Express API apps/api/src/modules/ 20+ route modules; authenticate + requireRole middleware
apiFetch() apps/web/src/lib/api/client.ts Auto-attaches JWT; 401 interceptor → silent refresh → retry
React Pages apps/web/src/app/ Role-based sidebar; canonical admin pattern (skeletons, empty states, toast)
SECURITY

Access Control Matrix

Endpoint Role Required Guard
GET /admin-stats/overview super_admin/school_admin/content_admin requireRole middleware
GET /batches/my teacher + admins requireRole + ownership check
GET /parent/children parent requireRole + link verification
GET /parent/children/:id/progression parent assertActiveLink FIRST, then service call
POST /users/:id/status super_admin/school_admin Cannot change own status → session invalidation on suspend
POST /auth/refresh any authenticated Re-reads roles from DB (live role changes apply)
DEMO

Investor Demo Script (6 min)

⏱️ 0:00-0:30 — Login as admin@
Admin dashboard shows REAL stats: 38 users, 626 questions, 9 assessments, 68 attempts. No fake "15,234 users" numbers. Pending teacher alert visible.
⏱️ 0:30-1:30 — Approve pending-teacher@
Go to /admin/users → see teacher awaiting approval → click Approve → PATCH status to ACTIVE → teacher can now log in (was blocked with "awaiting approval" message).
⏱️ 1:30-2:30 — Teacher: Real Class Data
Login as teacher@ → /dashboard/classes shows 2 batches with real memberCount (5-10 students) → /dashboard/reports shows real avgScore ~50% → /dashboard/questions shows 3 authored questions with topic links.
⏱️ 2:30-3:30 — Student: Progression + Attempt
Login as student@ → Dashboard shows Mastery Ladder across Grade 7-9 → Click Assessments → Start a Quiz → Answer questions → Submit → See score + weak topics identified → Progress saved to DB.
⏱️ 3:30-4:30 — Parent: Child Monitoring
Login as parent@ → /dashboard/children shows 3 children with link badges (ACTIVE/PENDING) → Child detail page → Tabs: Progress (MasteryLadder), Assessments (attempts table with scores), Study Plan (weak topics), Activity Feed → Real data from child's userId.
⏱️ 4:30-5:30 — Parent Invite + Student Approval
Parent invites student2@ → PENDING link created → Student2@ logs in → /dashboard/invites → sees invite → Approve → Link becomes ACTIVE → Parent can now see student2's data.
⏱️ 5:30-6:00 — Security Boundaries
Developer tab → Student token hits /batches/my → 403 Forbidden → Parent token hits another child's progression → 403 → These are enforced by requireRole + assertActiveLink, never client-side only.
